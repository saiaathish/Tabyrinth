# Third-party notices

## React Bits — Folder concept

TABYRINTH adapts the dependency-free folded-folder visual concept from React Bits for the Portal artifact. The shipped implementation is a small original CSS/React adaptation in `src/pages/portal/main.tsx`; it does not include the React Bits runtime or utility code.

React Bits source is distributed under the MIT License with the Commons Clause. The Commons Clause permits use inside an application while restricting resale or distribution as a standalone component library. This notice is retained with the adaptation.
